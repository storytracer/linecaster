    Blocks¶

    Every public block, by family: one page each with its contract, backends, options, behavior and where it comes in a pipeline. Terms are the glossary's; contracts and the builder are in pipelines.

    Readers¶

    linecaster.blocks.readers

    Block What it does
    ImageFolderReader Reads one page per image file of a folder or bucket.
    ImageParquetReader Reads one page per row of Parquet files with an image column.
    ManifestReader Reads one page per image of each item's manifest: IIIF Presentation 2 or 3, or METS with MODS (also inside an OAI-PMH response).
    PageRecordReader Reads the page records an earlier run wrote (JSON Lines or Parquet), so a pipeline can add one more part.
    PdfReader Reads one item per PDF file, one page per PDF page in order, each rendered to a lossless WebP image.

    Layout¶

    linecaster.blocks.layout

    Block What it does
    LayoutDetector Detects the layout regions of every page, with their labels and reading order, by a layout engine.

    Lines¶

    linecaster.blocks.lines

    Block What it does
    LineAssigner Assigns the lines detected on the whole page to the layout regions and orders them row by row.
    LineDetector Detects the text lines of every page, with their geometry, by a line detection engine.

    Recognition¶

    linecaster.blocks.recognition

    Block What it does
    FormulaRecognizer Recognizes every formula region as LaTeX by a formula engine.
    LineRecognizer Recognizes the text of every line by a line recognition engine.
    PageRecognizer Recognizes every page with a chat VLM, whose completion becomes the page's transcription.
    RegionRecognizer Recognizes each layout region of every page with a chat VLM, one request per region crop.
    TableRecognizer Recognizes the structure of every table region by a table engine.

    Conversion¶

    linecaster.blocks.conversion

    Block What it does
    ImageConverter Converts each page's delivered image into the working image with an image engine and writes it.
    ImageFetcher Loads each page's image again from its address, for the blocks that need pixels.
    TranscriptionConverter Reads the transcription file that comes with each page (ALTO, PAGE-XML, hOCR or plain text) into a named transcription.

    Text¶

    linecaster.blocks.text

    Block What it does
    CharacterNormalizer Normalizes the texts of every line, paragraph and table cell by a normalization engine, next to the text as written.
    UnicodeNormalizer Normalizes the as-written text of every line and word to one Unicode normalization form, NFC by default.

    Composition¶

    linecaster.blocks.composition

    Block What it does
    Composer Composes the DoclingDocument of a page or an item by a composition engine.
    Recomposer Recomposes the running text of a page or an item into paragraphs by a recomposition engine.
    Typographer Determines the typographic hierarchy of every page by a typography engine.

    Binding¶

    linecaster.blocks.binding

    Block What it does
    Binder Binds each item's page records, in order, into one item record.
    Splitter Splits each item record into its page records again, in the item's order, with what the item-level blocks added.

    Validation¶

    linecaster.blocks.validation

    Block What it does
    PageValidator Marks the page records that do not validate against Page or lack a required part with an error each.
    RecipeStamper Stamps the recipe edition a run follows on every step of every transcription, of a page or of each page of an item record.

    Servers¶

    linecaster.blocks.servers

    Block What it does
    ChatModelServer Starts a chat VLM server (vLLM or SGLang) inside the task for its Chat backends, through saturate's Engine.
    ModelServer Starts linecaster serve inside the task for its served model blocks, through saturate's Engine.

    Writers¶

    linecaster.blocks.writers

    Block What it does
    ImageFilesWriter Writes each page's image bytes as they came, one file per page.
    ItemDocumentWriter Writes the document of each item record, one file per format: Markdown, text, HTML, DocLang, JSON.
    ItemTextWriter Writes the text variants of each item record as JSON Lines or as files.
    PageFileWriter Writes one file per page and format: ALTO, PAGE-XML, hOCR, text, Markdown, HTML, DocLang, JSON and more.
    PageJsonlWriter Writes the page records as JSON Lines, one file per task, or into item shards for a later stage.
    PageParquetWriter Writes the page records as Parquet, one file per task.
    RejectWriter Writes every page that carries errors to the task's rejects file and passes every page on.

    Composites¶

    linecaster.blocks.composites

    Block What it does
    ModularTranscriber Reads a page's lines the modular way: layout, lines on the whole page, line assignment, line recognition.

    Base classes¶

    linecaster.blocks.base: what the blocks above are built on; no pages of their own.

    Class What it is for
    Composite Groups blocks under one name with an outward contract of its own.
    Contracted Gives a block the default contract(), read from its class attributes.
    ModelBlock Runs one model step's engine on every page, through its backend, and adds its part to the transcription.
    PageBlock Processes a stream of pages, one datatrove document per page, as the base of the page blocks.
    RuleBlock Runs a rule-based step's built-in engine on every page, in the pipeline's process, as the base of the rule blocks.
