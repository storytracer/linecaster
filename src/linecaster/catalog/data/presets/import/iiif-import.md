Reads an IIIF annotation page into a transcription (`import.iiif.v1`): linecaster's own and other software's that follow the same conventions (regions as `classifying` annotations, lines and words as `supplementing` ones with a `textGranularity`, edits as `editing` ones), with targets as media fragments in pixels or in percent of the page image, fragment or SVG selectors, and each body's language; a ground truth by default (the option `ground_truth`).
